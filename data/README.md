# Housing dataset

`house_prices.csv` is synthetic demonstration data generated for this project. It is not a record of actual property listings or transactions.

For a real-world analysis, replace it with a dataset you are permitted to use and record its title, source URL, license/usage terms, and download date.

Required columns:
- `area_sqft`: property area in square feet
- `bedrooms`: number of bedrooms
- `bathrooms`: number of bathrooms
- `age_years`: approximate property age
- `location`: city/category
- `price_inr`: target price in Indian rupees
